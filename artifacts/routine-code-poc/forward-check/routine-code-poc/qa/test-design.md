## 保証の範囲

この試験は単一スレッドで、正しい寿命・非重複領域を使う。ポインタの不正アドレスや重複領域は前提条件違反のため入力しない。NULL時に他ポインタを読み出していないこと、静的状態・外部呼出し・禁止構文の不存在は別途コード／オブジェクトレビューの対象とする。物理入力の連続性、周期欠落検出、WCET、同時実行排他、製品コンパイラとDLL ABI、RTOS接続、ランプ・画面・ログはこのホスト試験では検証しない。長さ11を超える全列や全int値の網羅を主張しない。試作仕様の未承認事項Q-01..04は残る。
