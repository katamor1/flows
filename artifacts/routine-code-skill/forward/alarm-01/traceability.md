## 呼出し側への割当

- 初回 `state.on_count = 0`。state/result と他の実行中呼出しの書込み領域を相互に重複させず、有効なメモリの寿命と他タスク・画面側からの同時参照/変更の防止を保証する。本体はポインタのNULLだけを検査し、有効性や領域の重複を検査しない。
- 同一周期の信号スナップショットから `signal_on` と `sample_valid` を渡す。周期欠落・PLC入力無効を検出したら、次の判定前に `sample_valid = 0` を通知する。
- 戻り値が0のときだけ結果を消費する。エラー時の旧 `became_qualified` を新規イベントとして再利用しない。
- U.XXXX入力取得、G.YYYY表示灯出力、画面向けメッセージ公開API、時刻取得、ZZZZログ追記予約、これらの失敗処理と排他、アラーム表示解除は別仕様・結合試験へ割り当てる。本体では実装していない。
