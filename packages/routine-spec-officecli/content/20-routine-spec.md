# プログラム仕様書作成のチーム規約

フルJSON正本からWordを作るときはroutine-spec-docスキルと固定OfficeCLIアダプターを使う。案件は.bobの外へ置き、正本とロックと.gitattributesを保持する。

任意のルーチンに新規案件を作れる。既存正本は--specで取り込み、ない場合は識別情報だけの未記入スケルトンを作る。Alarmの業務規則を自動注入せず、不明なAPIやエラーや承認を作らない。仕様変更は正本へ反映して再展開し、固定資材の改訂は保守作業へ分ける。

資材・実行実体の不一致や検査失敗では停止する。OOXML構造検査と内容/書式照合の成功を、全ページ表示確認・仕様承認・コード/RTOS/WCET試験合格と扱わない。Bobチャットからの起動確認も別項目である。
