# ルーチン仕様書作成のチーム規約

JSON正本からWord仕様書を作るときは、プロジェクトの `routine-spec-doc` スキルと固定OfficeCLIアダプターを使う。案件データは `.bob` の外へ置く。Word内部の変更はOfficeCLIが行い、JSON検証や編集命令を毎回作り直さない。

10周期ON判定のdraft_trial以外は未対応として不足を整理する。資材・実行バイナリの不一致や検査失敗は停止し、別版の導入・別の文書生成器への切替で回避しない。正本の仕様変更は再展開し、固定資材の改訂は保守作業へ分ける。

生成フローが残すOfficeCLI構造検査結果と内容照合結果を確認する。表示と業務内容は別途確認し、構造検査の成功を仕様承認・C90試験・RTOS性能の合格とみなさない。API名・呼出し文脈・時間予算は正式な案件資料に従う。
