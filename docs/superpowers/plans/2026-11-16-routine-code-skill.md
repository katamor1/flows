# IBM Bob向けC90コード生成スキル

目的: プログラム仕様書からC90コードを作成する再利用可能なBobスキルを配布する。今回の依頼はスキル作成と検証であり、以前中断したWord表示確認の再開は含めない。

- パッケージ: packages/routine-code-c90。プロジェクトに配布する配置は .bob/skills/routine-code-c90。
- スキル本文はC90/既存RTOS DLLの実装判断、仕様との対応、未決事項の扱いを示す。
- 一般のルーチンには正式API契約・ABI・ビルド/試験手順を使う。提供されていないSDKやエクスポートを推測しない。
- 自動検証の初版は検証済みアラーム仕様の入力ハッシュに限定する。別の仕様にアラーム用試験を適用しない。
- 既存 codeflow.py・ヘッダ・独立C試験・未実装スタブを固定資産として再利用する。本体の正解コードは配布資産に含めない。
- 固定codegen.pyで新規案件の準備、世代別生成記録、固定検証器の呼出しを行う。AIは本体と対応表を作り、ツール・ヘッダ・試験は再生成しない。
- 既存prototype、仕様書キット、コード生成PoCは変更しない。

実施順:

- [x] スキルなしの独立baselineを記録する。
- [x] スキル・参照資料・固定ツール・Bob配布ZIPを作る。
- [x] 入力差替え/固定資産変更/同名世代や案件への上書きを拒否する試験を行う。
- [x] 別コンテキストのエージェントでスキルからコードを生成し、実コンパイラで検証する。
- [x] ZIPの展開先でも同じ固定ツールが動作することを確認する。

制約: 今回の実行AIはCodex。Bob IDEでのスキル検出・実起動はこの実行の確認対象外として明記する。OSの認証・自動承認設定やグローバルなスキル配置は変更しない。
